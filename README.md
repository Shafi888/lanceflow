# 💼 LanceFlow — Freelancer Operations & Invoicing Suite

> A modern, offline-first Micro-SaaS application for independent freelancers, contractors, and boutique agencies. Manage clients, track billable sprint hours, generate professional PDF invoices, and monitor net profit margins.

---

## ✨ Features

- **📊 Financial Executive Dashboard**: Real-time KPI tracking for Gross Revenue, Net Profit (with profit margin %), Pending/Overdue Receivables, and Unbilled Hours.
- **🧾 Interactive Live Invoice Studio**:
  - Real-time letterhead preview as you type.
  - Multi-currency support (`USD`, `EUR`, `GBP`, `INR`, `CAD`, `AUD`).
  - Itemized line items with dynamic tax % and discount % calculations.
  - Pixel-perfect **Print & PDF Export** formatted for standard A4/Letter dimensions.
- **👥 Client CRM Directory**: Manage client profiles, default hourly rates, contact info, and lifetime financial histories.
- **⏱️ Billable Time Tracker & 1-Click Auto-Invoicing**: Integrated stopwatch timer that allows you to select unbilled sprint logs and convert them directly into an itemized draft invoice with 1 click.
- **📉 Expense & Profit Tracker**: Categorize business write-offs (Software, Infrastructure, Equipment, Contractors) with automatic net profit calculation.
- **🔒 Privacy-First & Offline-Ready**: All data stays securely in local device storage with full JSON Backup / Restore support.

---

## 🚀 Quick Start (Run Locally)

1. Clone or download this repository:
   ```bash
   git clone https://github.com/YOUR_USERNAME/lanceflow.git
   cd lanceflow
   ```
2. Simply double-click `index.html` to run in any browser (Chrome, Edge, Safari, Firefox). Zero web server or node installation required!
